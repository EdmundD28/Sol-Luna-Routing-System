# P005 field pilot — structural allowance evidence

Status: `HOLD_SOL_ONLY`. This is a single matched pilot, not a production-routing claim.

## Frozen comparison

- Baseline: `73b56e41a32a7098e2802203607f0e7c6b499993` (`v0.11.0`).
- Task: implement the same schema-4 structural net-substitution evidence contract.
- Sol-only: one `gpt-5.6-sol/high` controller, one continuous top-level run, no workers.
- Sol-Luna: one `gpt-5.6-sol/high` controller and exactly one retained
  `gpt-5.6-luna/high` writer.
- Both candidates used the same repository and separate Git branches. No clone,
  copy, worktree, deployment, network action, or hidden-test access was allowed.
- A common hidden referee ran only after each route returned.

The Sol-Luna route was 2.17x slower. Its displayed five-hour consumption was
5x the Sol-only reading, but that ratio is not a route-only cost estimate:
the controller thread monitored route progress throughout both intervals; the
Luna arm additionally required child-worker polling and, because it ran longer,
caused more controller turns. The shared plan meter includes that controller
activity. The between-arm referee and Git interval also moved
the display from 77% to 76%. Delayed dashboard accounting is another possible
contributor. Therefore the economic result is only: **no allowance advantage
was demonstrated, and the observed whole-session experience regressed**.

## Why the collaboration failed

Luna implemented all eight owned paths, ran the full suite, and completed one
focused repair. Sol then added ten tests, restored economic and elapsed gates
that Luna had removed, corrected legacy status handling, and edited the same
coarse acceptance scope. The frozen plan had one broad coverage claim, so the
Sol replay shadowed the entire claim. Passing tests proved final quality, but
did not prove that Luna replaced Sol work.

This failure is not evidence that fewer Luna calls are the answer. It shows
that useful Luna participation needs a closure protocol:

1. Freeze several acceptance-bound responsibility units inside one stable Luna
   envelope; units are not extra workers or extra handoffs.
2. Reserve a disjoint Sol lane for adversarial acceptance and integration
   preparation while Luna implements.
3. Return review failures to the same Luna while marginal net substitution is
   still positive; do not reclaim after one arbitrary repair.
4. Forbid Sol edits to Luna-owned unit paths before an explicit reclaim. A
   reclaim shadows only affected units, never unrelated accepted units.
5. Keep route-independent referee work outside both route intervals and make
   the experiment controller quiet between the start and end meter readings.

## Next measurement boundary

The next matched run must take one fresh start reading, suspend controller
sampling while the route runs, take one end reading before the same reset, and
then run the common referee. Five-hour percentage points remain primary;
weekly percentage points remain separate corroboration. A single pair can
reject a route, but cannot establish a general advantage.
