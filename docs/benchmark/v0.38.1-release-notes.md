# v0.38.1 batched controller acquisition

Status: experimental controller-cost reduction. It changes one observed Sol hot-path action and does not claim full-route or included-plan superiority.

## Change

When the Skill, frozen task contract, named dependencies, acceptance inputs, and test listing are already known, Sol acquires them in one bounded read action rather than separate model turns. The rule removes no input, does not weaken the launch-ready acceptance capsule, and adds no protocol, tool, artifact, or Luna work.

## Evidence

P122 replayed the P121 controller's four pre-dispatch acquisitions as one frozen command with the same installed Skill, task specification, public test body, and test-file listing. A fresh `gpt-5.6-sol/high` controller made exactly one command call, spawned no child, and emitted the complete launch-ready capsule.

| Measure | P121 four-turn prefix | P122 one-turn acquisition | Change |
|---|---:|---:|---:|
| Purchased-credit-equivalent proxy | 3.829540 | 2.181700 | -43.029711% |
| Natural elapsed time | 55.074 s | 27.616 s | -49.856557% |

The proxy uses complete cumulative session counts and the frozen Sol rates: non-cached input `100`, cached input `10`, and output `500` per million. Reasoning is included in output and is not charged twice. Independent review reproduced the counts, arithmetic, one-call boundary, and capsule completeness.

## Limits

- This is a controller-only microbenchmark, not an implementation route.
- It does not prove route quality, route-level credit or time superiority, or five-hour/weekly allowance savings.
- P121 remains `HOLD_SOL_ONLY`; its full Medium route failed both the accepted-cost and elapsed gates.
- P118's failed reference-only handoff is not retried: v0.38.1 preserves the public-test contents, test listing, executable, arguments, and workdir.

## Full-route follow-up

The later same-task P118 v0.38.2 ablation preserved equal public and hidden quality but did not transfer the P122 microbenchmark gain. Complete Sol-Luna credit equivalent was `4.913135`, only `41.478808%` below Sol-only, and elapsed time was `185.211` seconds, `19.004967%` slower than Sol-only. The controller obeyed the one-read, one-spawn, one-wait sequence and Sol performed no implementation or replay, so the failure is not an orchestration-compliance artifact.

This closes further batching-only work under the current premise. v0.38.3 removes the one-sentence ordinary-path requirement after the full-route rejection; the controller-only microbenchmark is retained as diagnostic evidence, not product policy.
