## v0.37.5 — Prior-attempt release gate

Every guarded release must now cite the versioned attempt index before any GitHub write. The release entry must identify the prior mechanism families reviewed, classify the proposal as a new direction or a retry with a changed premise, cite its evidence, and disclose its normal-path cost. Missing history, unknown family references, and premise-free retries fail before the network release check.

The initial index compresses v0.2.0 through v0.37.4 into nine mechanism families with observed results and explicit repeat rules. It records negative evidence as a constraint, not as an invitation to rerun the same idea under a new experiment number.

This gate is used only for product research and release. It is not installed with the Skill and adds no ordinary Sol-Luna dispatch action, message, manifest, test, or receipt.

Validation: 11 focused release tests and 454 full repository tests passed with 4 platform skips; `git diff --check` passed. This release makes no included-plan allowance claim. P085 found equal frozen quality, 22.202% lower route-boundary elapsed time, and 32.096% lower combined non-cached diagnostic input for v0.37.4 versus v0.1.1, while both official allowance changes remained below one displayed percentage point. `v0.1.1` remains GitHub Latest.
