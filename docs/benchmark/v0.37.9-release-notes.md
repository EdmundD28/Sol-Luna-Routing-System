# v0.37.9 single completion wait

Status: important experimental economic-path milestone. It is the first indexed equal-quality matched route to clear the 50% credit-equivalent reduction target against Sol-only, but it does not establish included-plan percentage savings or an overall time win against Sol-only.

## Problem

On P117, one retained Luna completed a bounded implementation in about 233 seconds while its Sol controller called four one-minute waits. Every timeout reactivated the full Sol context. After completion the controller also enumerated every live agent, adding another Sol turn and exposing the other matched arm's result summary. None of these wakeups advanced implementation or acceptance.

## Change

When Sol has no useful path-disjoint work, it performs one long wait on the retained Luna until normal completion. Ordinary success forbids periodic status polling, global agent enumeration, and commentary-triggered wakeups. The change replaces an existing sentence and leaves the Skill at 1,200 words; it adds no tool, manifest, receipt field, ledger, or model round.

## Evidence

The frozen P117 unseen-task pair produced equal implementation quality: both Sol-only and the original Sol-Luna route passed 19/19 public and 10/10 route-external hidden checks with zero repair; Sol-Luna performed no Sol rewrite or reclaim.

Using complete fresh-session host token counts with the official standard-speed model credit rate card:

- Sol-only: `10.323980` credit equivalent, `241.744` seconds;
- original Sol-Luna: `8.063423`, `335.215` seconds;
- single-wait Sol-Luna ablation: `4.626947`, `300.868` seconds.

The single-wait candidate reduced the same-task Sol-Luna proxy by `42.618079%` and elapsed time by `10.246%`. Relative to Sol-only it used `55.182527%` fewer credit-equivalent units, but remained `24.457%` slower. The candidate controller used exactly `exec, spawn_agent, wait_agent`; the writer again passed 19/19 public and 10/10 hidden checks with no repair or Sol implementation.

## Limits

- The official purchased-credit equivalent is a temporary relative proxy, not the five-hour or weekly included-plan meter.
- The ablation repeats the same development task, so it isolates the waiting mechanism but is not a second independent task-family sample.
- The writer's final `READY` omitted the requested `git diff --check` exit code. A route-external mechanical check returned zero, so implementation quality passed, but the in-route evidence capsule had that gap.
- The release passes the `50%` credit-proxy reduction target on this pair but not the no-time-regression target against Sol-only. It therefore remains experimental and non-Latest.
